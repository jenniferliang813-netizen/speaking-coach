# 每日英文口說教練

每天 5 分鐘、開口說英文的練習 App。目標：2026 年 9 月底愛爾蘭學術報告前，把「醫學報告口說＋研討會閒聊＋旅行英文」練起來。

## 🌐 線上版網址（手機、電腦都用這個）

**https://jenniferliang813-netizen.github.io/speaking-coach/**

> ⚠️ 不要再雙擊 `index.html` 開了——瀏覽器會封鎖「檔案直開」模式的麥克風，語音辨識不會動。一律用上面的網址。

## 📱 手機安裝成 App（一次設定，30 秒）

- **Android（Chrome）**：開上面的網址 → 右上角「⋮」→「加到主畫面」（或會自動跳出「安裝」提示）→ 桌面出現「口說教練」圖示，點開就是全螢幕 App。
- **iPhone（Safari）**：開上面的網址 → 下方「分享」按鈕 □↑ →「加入主畫面」。
  - iPhone 注意：如果安裝後的 App 裡麥克風不會動，改用 Safari 直接開網址練習即可（iOS 對主畫面 App 的麥克風支援不穩定）。

第一次按麥克風會問權限，按「允許」。

## 每天怎麼用（只有這 3 步）

1. 打開手機桌面的「口說教練」（或瀏覽器開上面網址）。
2. 按「開始今天的練習」→ 先跟讀 3 張句型卡 → 進入 3 回合對話（教練說一句、你按麥克風回答一句）。
3. 看成績單 → 按「完成」。結束，關掉。

聲音有問題時：進 ⚙ 設定按「🔊 測試教練聲音」，會顯示目前用哪個語音。

聽不懂教練說什麼：按 🔁 重播或 🐢 慢速。想不出怎麼回答：按 💡 提示。

## 每週一次（用 Claude Code，不花 API 費）

- **換新題目**：在本資料夾開 Claude Code，說「照 prompts/generate-week.md 產生下一週內容」。Claude Code 會產完自動推上 GitHub，**手機重新開 App 就是新題目**。
- **匯出弱點**（建議先做）：App 首頁按「📤 匯出弱點」，把下載的 `_weak.json` 放進 `content\` 資料夾，新題目就會針對你的弱項加強。

## 想要深度批改時（不定期）

App 成績單按「📄 匯出逐字稿」→ 開 Claude Code 說「照 prompts/deep-review.md 批改這份逐字稿」，附上下載的檔案路徑。

## 檔案地圖

| 檔案 | 是什麼 | 可以動嗎 |
|---|---|---|
| `index.html` | 練習 App 本體 | 修改請透過 Claude Code |
| `content/current-week.js` | 本週題庫 | 每週由 Claude Code 覆寫 |
| `content/archive-*.js` | 歷史題庫備份 | 不用管 |
| `content/_used.json` | 出過的題目清單（防重複） | 不要手動改 |
| `content/_weak.json` | 你匯出的弱點統計 | 每週從 Downloads 搬進來 |
| `prompts/` | 給 Claude Code 的兩份工作指令 | 可請 Claude Code 調整 |
| `BUILD_SPEC.md` | App 的完整規格書 | 改功能前先看它 |

## 注意事項

- 練習紀錄存在**該裝置的該瀏覽器**裡（localStorage）。手機練的紀錄在手機、電腦練的在電腦，**不會互通**；主要用手機練就固定用手機，紀錄才連得起來。清瀏覽器資料會清掉紀錄。
- 語音辨識需要網路（聲音送雲端辨識），離線時只能看題目不能練口說。
- 腔調預設英國腔，**2026-08-01 起自動改用愛爾蘭腔**（也可以隨時在 ⚙ 設定手動切換）。
